Khóa API Cá Nhân (API Key)

Không chia sẻ API Key cho bất kỳ ai để bảo vệ số dư tài khoản.

API Endpoint (URL Kết Nối)

Phương thức: POST • Định dạng: JSON

Lấy toàn bộ danh sách dịch vụ & đơn giá

POST Parameters:

key : YOUR_API_KEY

action : "services"

Mẫu JSON phản hồi:

[
  {
    "service": 1,
    "name": "Like Bài Viết Facebook [Tốc độ cao]",
    "type": "Default",
    "category": "Facebook Like",
    "rate": "12.00",
    "min": "50",
    "max": "50000"
  },
  {
    "service": 7,
    "name": "Followers TikTok Việt Nam [Bảo hành 30 ngày]",
    "type": "Default",
    "category": "TikTok Follow",
    "rate": "45.00",
    "min": "100",
    "max": "50000"
  }
]

Tạo đơn hàng mới qua API

POST Parameters:

key : YOUR_API_KEY

action : "add"

service : ID_DICH_VU (ví dụ: 1)

link : "https://facebook.com/..."

quantity : 1000

Mẫu JSON phản hồi khi thành công:

{
  "order": 10842,
  "status": "success",
  "charge": "12000"
}

Kiểm tra trạng thái đơn hàng

POST Parameters:

key : YOUR_API_KEY

action : "status"

order : 10842

Mẫu JSON phản hồi:

{
  "charge": "12000",
  "start_count": "520",
  "status": "In progress",
  "remains": "150",
  "currency": "VND"
}

Kiểm tra số dư ví tài khoản

POST Parameters:

key : YOUR_API_KEY

action : "balance"

Mẫu JSON phản hồi:

{
  "balance": "550000.00",
  "currency": "VND"
}

Code Mẫu Tích Hợp (SDK / Examples)

Ví dụ gọi API tạo đơn bằng JavaScript (Fetch):

const res = await fetch("https://fvkwcmztfxmdvyjlqcve.supabase.co/api/v2", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    key: "YOUR_API_KEY",
    action: "add",
    service: 1,
    link: "https://facebook.com/posts/123456",
    quantity: 1000
  })
});
const data = await res.json();
console.log(data);
